\section*{2. Detailed Calculations by Category}
% ============================================================

\subsection*{Category 1 -- Transport}

\begin{itemize}
    \item Mode of transport: personal car, driver alone
    \item Distance from home to E-Tafakna: 85 km (one way)
    \item Round trip per day: 170 km
    \item Number of on-site days: 26 days (2 days/week $\times$ 3 months $\approx$ 13 weeks)
    \item Total distance: $26 \times 170 = 4\,420$ km
    \item Emission factor (EF) adjusted for Tunisia: 0.24 kg CO$_2$e/km/vehicle
\end{itemize}

\[
\text{Emissions} = 4\,420 \times 0.24 = \mathbf{1\,060.8\text{ kg CO}_2\text{e}}
\]

\subsection*{Category 2 -- Computing Hardware}

\begin{itemize}
    \item Model: ASUS TUF Gaming FA506N (RTX~3050, Ryzen~5 7000 series, 32~GB RAM, 15.6-inch screen) -- pre-existing personal equipment
    \item PCF source: official ASUS FA507NU report (same TUF series, same generation, same 15.6-inch form factor), certified ISO~14067:2018, published February 2024
    \item Total lifecycle PCF declared by ASUS: \textbf{336 kg CO$_2$e}
    \item Manufacturing phase: \textbf{71\,\% of total} $= 336 \times 0.71 = 238.6$ kg CO$_2$e
    \item The use phase (24.8\,\%, i.e. 83.3 kg CO$_2$e) is excluded here as laptop electricity consumption is already counted in Category~3A
    \item Official ASUS lifetime: \textbf{4 years = 48 months}
    \item Internship attribution period: \textbf{3 months}
\end{itemize}

\[
\text{Emissions} = 238.6 \times \frac{3}{48} = \mathbf{14.9\text{ kg CO}_2\text{e}}
\]

\subsection*{Category 3 -- Infrastructure \& Code}

\textbf{A. Local laptop power consumption:}
\begin{itemize}
    \item Average power draw: 0.075 kW (midpoint of the 0.05--0.1 kW range for laptops)
    \item Usage: 7 h/day $\times$ 65 working days = 455 h
    \item Tunisia electricity emission factor: 0.545 kg CO$_2$e/kWh
\end{itemize}
\[
0.075 \times 455 \times 0.545 = \mathbf{18.6\text{ kg CO}_2\text{e}}
\]

\textbf{B. Cloud server -- OVHcloud (model training):}
\begin{itemize}
    \item GPU: NVIDIA V100S (300\,W); estimated server power: 0.5 kW
    \item OVHcloud PUE: 1.30; France electricity EF (nuclear): 0.052 kg CO$_2$e/kWh
    \item Gemma 4 E4B: 3\,357 s = 0.93 h $\Rightarrow$ $0.5 \times 0.93 \times 1.30 \times 0.052 = 0.032$ kg CO$_2$e
    \item Qwen3.5 9B: 15\,223 s = 4.23 h $\Rightarrow$ $0.5 \times 4.23 \times 1.30 \times 0.052 = 0.143$ kg CO$_2$e
\end{itemize}
\[
\text{OVHcloud subtotal} = \mathbf{0.18\text{ kg CO}_2\text{e}}
\]

\textbf{C. Cloud APIs (GPT-4.1 / Gemini):}
\begin{itemize}
    \item GPT-4.1 (Azure) -- article extraction and dataset synthesis: $\approx$300 requests $\times$ 7 g CO$_2$e = 2.1 kg CO$_2$e
    \item Gemini (Google Cloud Vertex AI) -- hybrid OCR: $\approx$200 requests $\times$ 5 g CO$_2$e = 1.0 kg CO$_2$e
\end{itemize}
\[
\text{APIs subtotal} = \mathbf{3.1\text{ kg CO}_2\text{e}}

\textbf{D. Data transfers:}
\begin{itemize}
    \item GGUF model files (2 models $\times$ 5 GB) + dependencies + git + browsing: $\approx$60 GB

60 \times 0.02 = \mathbf{1.2\text{ kg CO}_2\text{e}}

\section*{3. Improvement Proposals}
% ============================================================

The analysis shows that transport accounts for 96.1\,\% of the project's total emissions, making it by far the most significant lever for reduction.

\textbf{Transport (priority lever):}
\begin{itemize}
    \item Reduce on-site presence from 2 to 1 day per week, cutting transport emissions by approximately 50\,\% ($-$530 kg CO$_2$e).
    \item Carpooling with other students or colleagues from the same area, dividing the emission factor by the number of passengers.
    \item For internships in Tunisia, favour shared long-distance transport (bus, louage) where available, with an emission factor roughly 18 times lower than a solo car journey.
\end{itemize}

\textbf{Digital infrastructure (Green IT):}
\begin{itemize}
    \item \textbf{Efficiency:} Choose low-carbon datacenters for training workloads. OVHcloud (France, 0.052 kg CO$_2$e/kWh) was an effective choice: fine-tuning two LLMs accounted for less than 0.02\,\% of total emissions, demonstrating the impact of nuclear-powered compute.
    \item \textbf{Frugality:} Apply model quantization (GGUF q4\_k\_m) from the testing phase rather than only in production, and reduce training iterations through prior hyperparameter search.
    \item \textbf{Hardware:} Extend the life of personal equipment and avoid purchasing new devices when existing hardware is sufficient.
\end{itemize}

\textbf{Printing and office:}
\begin{itemize}
    \item Share the report digitally (PDF) and print only one double-sided final copy on recycled paper.
    \item Use recycled or second-hand stationery.
\end{itemize}

\textbf{Reflection on technical choices:}
This project illustrates an important reality: in a final year project with a strong AI component, cloud computing emissions are in practice very small when the provider runs on low-carbon energy. The dominant source of emissions remains daily physical commuting, which is independent of the project's technical content. Embedding digital frugality from the design phase (quantization, API batching, reduced training iterations) is nonetheless a sound professional practice worth generalizing.
